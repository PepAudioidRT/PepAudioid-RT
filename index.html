Give your hardware a second life

Old Hardware. Real-Time Audio.

Your old PC might still have a lot of music left in it. PepAudioid RT explores how older desktops and laptops can become dedicated digital audio players, using a lightweight Linux environment, MPD, ALSA and a USB DAC.

▣

HP 280 G2 · Intel Core i3-6100

Our development and audio-testing platform. A modest desktop running a custom PREEMPT_RT kernel, MPD and ALSA with a Musical Fidelity V90-DAC.

31 µs highest observed series-wide worst-case scheduling latency across three recorded RT test series.

No expensive modern CPU is required for basic lossless audio playback. Actual compatibility and real-time performance depend on the hardware. Low scheduling latency does not, by itself, demonstrate superior audible sound quality.

Get started · Experimental Live ISO

Download, verify & boot

No Linux installation is needed to create the USB drive. Follow these steps on Windows, Linux or macOS to try PepAudioid RT without replacing your existing operating system.

1 Download the Live ISO

Get PepAudioid RT v0.1.0 — Experimental Live Preview from the official GitHub release. Download PepAudioid_RT1_live-x86_64.iso and the accompanying SHA256SUMS file.

Open v0.1.0 release ↗

2 Verify the ISO (SHA-256)

A SHA-256 checksum is a digital fingerprint of the downloaded file. Compare the result on your computer with the value published for this release. The values must match exactly; if they do not, download the ISO again and do not write it to USB.

Expected SHA-256 for PepAudioid_RT1_live-x86_64.iso:

c916504f29c3dc84db44e0d520ab6f1370327c192c75a047a1c748fe3d12abd5
Windows — PowerShell

Open PowerShell in the folder containing the downloaded ISO and run:

Get-FileHash .\PepAudioid_RT1_live-x86_64.iso -Algorithm SHA256
Linux — Terminal

Open a terminal in the download folder and run:

sha256sum PepAudioid_RT1_live-x86_64.iso
macOS — Terminal

Open Terminal in the download folder and run:

shasum -a 256 PepAudioid_RT1_live-x86_64.iso

You can also compare against the SHA256SUMS file from the same GitHub release.

3 Create a bootable USB drive

Easy method (Windows, Linux and macOS): use balenaEtcher. Insert a spare USB drive (4 GB or larger recommended), choose Flash from file, select the PepAudioid RT ISO, select the correct USB drive and click Flash!. Wait for writing and validation to finish.

Windows alternative: Rufus. Select your USB device and ISO, start writing, and choose DD Image mode if Rufus asks how to write the image.

Advanced Linux method — dd

Identify the entire USB device (for example /dev/sdb) using:

lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS

Unmount any mounted partitions on that USB drive, then run from the folder containing the ISO:

sudo dd if=PepAudioid_RT1_live-x86_64.iso \
  of=/dev/sdX bs=4M status=progress conv=fsync

Replace /dev/sdX with the whole USB device, not a partition such as /dev/sdX1. Wait until the command completes before removing the drive.

Warning: flashing the ISO erases all existing data on the selected USB drive. Double-check the destination before proceeding. balenaEtcher and Rufus are third-party tools, not PepAudioid RT software.

4 Boot PepAudioid RT

Insert the USB drive into the computer you want to test. Restart it, open its firmware boot menu (the key varies by manufacturer) and select the USB drive.

Choose a suitable entry from the Live boot menu. The regular Live option runs from the USB image; a Run from RAM option is also available and needs sufficient system memory. Other boot entries may be offered for compatibility.

For the tested v0.1.0 Live environment, log in with username anon and password voidlinux.

Live testing does not require installing PepAudioid RT on the computer's internal drive. Hardware compatibility is not guaranteed.

Security: these are publicly known default credentials. Do not enable remote access such as SSH on untrusted networks without changing the credentials and securing the service.

5 Connect your DAC & explore

Connect a compatible USB DAC to your amplifier, headphones or speakers. PepAudioid RT focuses on the MPD → ALSA → USB DAC audio path. Audio output and music-library setup may require configuration for your specific hardware; automatic detection and ready-to-play operation are not guaranteed in this experimental release.

Share your PC model, DAC, playback observations and any scheduling-latency results in GitHub Issues.

PepAudioid RT v0.1.0 is an experimental preview, not a production-ready operating system. A future ISO version is under development.
